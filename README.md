# Mini-S4

A tiny language model based on S4 (structured state space), built from the simplified example in the MM-ISI course.
It is trained in MATLAB and runs in plain C on small hardware:

- **v1 runs on a Raspberry Pi**: it reads two words and guesses the third. Example: "Marcel schimba" -> PLC.
- **v2 runs on an ESP32**: it continues whole sentences, and it can also act as an Ollama server, so chat apps can talk to it.

The training sentences are in Romanian, about people repairing devices in a factory.

| | v1 - Raspberry Pi | v2 - ESP32 |
|---|---|---|
| What it does | guesses the 3rd word from 2 | continues a sentence until "." |
| Words it knows | 10 | 39 |
| Memory size (N) | 2 | 32 |
| Training | `pinv` (least squares) | gradient descent on cross-entropy |
| Runs on | Raspberry Pi (any computer with gcc) | ESP32 (ESP32-WROOM boards) |
| How you use it | command line | Serial Monitor, or a chat app via the Ollama API |

## Folder structure

    v1_raspberry_pi/

        s4_basic.c             runs the model in C, with the trained values written in the code
    v2_esp32/

        mini_s4_api/           ESP32 sketch: Ollama-compatible server for chat apps
            secrete_exemplu.h  Wi-Fi name and password template (copy to secrete.h, which git ignores)

## How it works

Both versions use the same state-space system:

    x(k+1) = A*x(k) + B*u(k)      memory
    y      = C*x                  scores

1. Each word has a fixed label: one column of `B`.
2. The memory `x` starts empty. At each word it fades (multiplied by `A`) and adds that word's label.
3. The score of each possible next word is one row of `C` multiplied by the memory.
4. Softmax turns the scores into percentages.

Only `C` is trained. `A` and `B` stay fixed.

## v1 - Raspberry Pi

`A = 0.95`, and each word's label is 2 random numbers. `C = T*pinv(H)`, where the columns of `H` are the final memory of each training sentence and `T` holds the correct answer for each one.

Vocabulary: Marcel, Alina, George, schimba (replaces), repara (repairs), monteaza (installs), modul, PLC, motorul (the motor), HMI.
Training sentences: `Marcel schimba -> PLC`, `Alina repara -> motorul`, `George monteaza -> HMI`.

| Input | Answer | Probability |
|---|---|---|
| Marcel schimba | PLC | 54% |
| Alina repara | motorul | 43% |
| George monteaza | HMI | 39% |
| Marcel repara (not in training) | PLC | 65% |

**Training** (MATLAB): in the `v1_raspberry_pi` folder, type `antrenare` in the Command Window. It prints `H`, `C`, the results for the 3 sentences, and the values of `B` and `C` in the format used by `s4_basic.c`.

**Running** (on the Raspberry Pi, or any computer with gcc):

    gcc -o s4_basic s4_basic.c -lm
    ./s4_basic 0 3

The arguments are word indices: 0 Marcel, 1 Alina, 2 George, 3 schimba, 4 repara, 5 monteaza.

## v2 - ESP32

A bigger model (39 words, 32 sentences) that finishes your sentence word by word:

    urmeaza: PLC-ul 97%   cablul 2%   de 0%
    propozitie: Marcel repara PLC-ul din hala .

(`urmeaza` is the next-word prediction, `propozitie` the finished sentence.)

There are two sketches. `mini_s4` works over USB in the Serial Monitor. `mini_s4_api` connects to Wi-Fi and answers like an Ollama server, so chat apps such as Page Assist or Open WebUI can use it as the model `mini-s4`.

Setup, training and the chat API are explained in [v2_esp32/README.md](v2_esp32/README.md).
